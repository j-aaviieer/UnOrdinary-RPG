# UnOrdinary-RPG

Prototipo inicial de un RPG 2D de exploración inspirado en el universo del webtoon *unOrdinary*. Fan game no oficial, sin afiliación con sus creadores ni titulares.

## Ejecutar
1. Clona o descarga este repositorio.
2. Abre la carpeta en VS Code.
3. Ejecuta `index.html` con Live Server.
4. Se necesita conexión a internet para cargar Phaser 3 desde CDN.

## Controles
- **W A S D:** moverse.
- **Shift:** correr.
- **E:** interactuar con personajes cercanos.
- **Q:** activar/desactivar aura.
- **Esc:** cerrar ventanas.

## Prototipo 0.1
- Escenario inicial de Wellston dibujado con Phaser.
- Movimiento, cámara de seguimiento y límites del campus.
- NPC de demostración: John, Seraphina y Arlo.
- Diálogos y relaciones individuales.
- HUD con vida, aura, dinero, habilidad y reputación.
- Ventanas de misiones, perfil y teléfono.
